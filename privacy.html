AETHER · PRIVACY POLICY

Last updated: 10 September 2026

AETHER is a personal, single-user application. It is installed and run by one person on their own computer, and it acts only on that person's own Google account. It is not offered as a service, has no users other than its owner, and collects no information from anyone else.

WHAT DATA THE APPLICATION ACCESSES

After the owner grants consent through Google's standard OAuth screen, the application can:

  • Upload videos, thumbnails and caption tracks to the owner's own YouTube channel, and manage the videos it created there.
  • Read statistics for the owner's own YouTube channel — views, watch time, subscribers — in order to build a private performance report.
  • Send that report by email, from the owner's own Gmail account, to the owner's own email address.

The application does not read the owner's inbox, does not access contacts, files, calendar or any other Google data, and cannot access any account other than the one that granted consent.

WHERE DATA IS STORED

The OAuth credentials issued by Google are stored in a single file on the owner's own computer and are used solely to call the Google APIs listed above. Video scripts, imagery, rendered files and reports are likewise stored only on that computer. Nothing is uploaded to any server operated by the developer, because no such server exists.

WHAT IS NOT DONE WITH THE DATA

  • It is never sold, rented or traded.
  • It is never transferred to third parties, advertisers, analytics providers or data brokers.
  • It is never used to train artificial-intelligence or machine-learning models.
  • It is never used for advertising or profiling of any kind.
  • No human other than the owner ever reads it.

GOOGLE API SERVICES USER DATA POLICY

AETHER's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through those APIs is used only to provide the functionality described on this page and is not used for any other purpose.

RETENTION AND REMOVAL

The owner can revoke the application's access at any time from Google Account permissions. Deleting the stored credential file on the computer removes the application's ability to act on the account immediately. Since all other data lives on that same computer, deleting the application's folder removes it entirely.

CHILDREN

The application is not directed at children and collects no information from anyone, of any age, other than its own owner.

CHANGES

If what the application does with Google data ever changes, this page is updated before the change takes effect.
