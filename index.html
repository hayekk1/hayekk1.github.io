AETHER · AUTOMATED DOCUMENTARY CHANNEL

AETHER is a personal, single-user application that produces and publishes long-form documentary videos to one YouTube channel — the channel belonging to the person running it. It runs on that person's own computer. There is no website to sign up for, no account to create, and no service offered to anyone else.

WHAT IT DOES

Once a day it reads public trend feeds, selects one subject with genuine substance behind it, writes a documentary script, sources public-domain and Creative Commons imagery with attribution, narrates it, renders a video, runs an editorial quality check, and — if that check passes — uploads the result to its owner's YouTube channel.

WHY IT NEEDS GOOGLE ACCESS

  • YouTube Data API — to upload the video, thumbnail and caption track to the owner's own channel.
  • YouTube Analytics API — to read the owner's own channel statistics for a private performance report.
  • Gmail API — to send that report to the owner's own email address, and nowhere else.

All three act only on the account of the person who installed and authorised the application.

SOURCE MATERIAL

Imagery comes from Wikimedia Commons and Openverse under public-domain or Creative Commons terms, and attribution is written into every video description automatically. Narration is AI-assisted and disclosed as such on every video.
